# Worms: Pocket Artillery

A small, turn-based artillery game for two local players. Adjust your aim, account for the wind, and fire rockets across the arena.

**[Play Worms: Pocket Artillery](https://guantong.github.io/worms-clone/)**

## How to play

Players take turns aiming and firing. Change the angle and power to hit your opponent. The active worm can also be moved a short distance horizontally by dragging it.

### Controls

| Action | Control |
| --- | --- |
| Adjust angle | Up / Down arrow keys or the angle buttons |
| Adjust power | Left / Right arrow keys or the power buttons |
| Fire | Space bar or the **Fire Rocket** button |
| Aim | Click the arena |
| Move the active worm | Drag it horizontally in the arena |

Random wind is enabled by default and changes from turn to turn. Use the wind toggle to turn it off.

## Run locally

The game is a standalone HTML page with no build step or dependencies:

1. Clone or download this repository.
2. Open `index.html` in a modern web browser.

## GitHub Pages

To publish the game with GitHub Pages, open the repository's **Settings → Pages** and choose **Deploy from a branch**, then select the `main` branch and the `/ (root)` folder.
